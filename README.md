# タイマー＆ストップウォッチ アプリケーション

これは、タイマーとストップウォッチ機能を提供するシンプルなWebアプリケーションです。

## 特徴

- **タイマー機能**:
  - 時間、分、秒を指定してカウントダウンします。
  - 拡張モードで簡単に時間を追加できます（+1分, +3分, +5分）。
- **ストップウォッチ機能**:
  - ミリ秒単位での時間計測が可能です。
  - 一時停止、再開に対応しています。
- **レスポンシブデザイン**:
  - PCの全画面表示、スマートフォンの小さい画面表示の両方に最適化されています。
- **Docker対応**:
  - Docker Compose を使って簡単に開発環境を起動できます。

## 起動方法

### 前提条件

- [Docker](https://www.docker.com/get-started)
- [Docker Compose](https://docs.docker.com/compose/install/)

### 手順

1.  このリポジトリをクローンまたはダウンロードします。
2.  ターミナルでこのプロジェクトのルートディレクトリに移動します。
3.  以下のコマンドを実行して、コンテナをビルドし、バックグラウンドで起動します。

    ```bash
    docker-compose up --build -d
    ```

4.  Webブラウザで `http://localhost:5000` を開きます。

アプリケーションを停止するには、以下のコマンドを実行します。

```bash
docker-compose down
```

## 使用方法

### タイマー

1.  **時間設定**: 「時間」「分」「秒」の各入力ボックスに直接数値を入力するか、横の矢印で値を調整します。
2.  **スタート**: 「スタート」ボタンを押すと、カウントダウンが開始されます。
3.  **ストップ**: 「ストップ」ボタンを押すと、タイマーが一時停止します。
4.  **リセット**: 「リセット」ボタンを押すと、時間が初期状態（00:00:00）に戻ります。
5.  **拡張モード**:
    - 「拡張モード」のチェックボックスをオンにすると、「+1分」「+3分」「+5分」ボタンが表示されます。
    - これらのボタンを押すと、現在の「分」の入力値に時間が追加されます。

### ストップウォッチ

1.  **タブ切り替え**: 画面上部の「ストップウォッチ」タブをクリックします。
2.  **スタート**: 「スタート」ボタンを押すと、時間の計測が開始されます。
3.  **一時停止**: 「一時停止」ボタンを押すと、計測が一時停止します。再度「スタート」ボタンを押すと、計測が再開されます。
4.  **リセット**: 「リセット」ボタンを押すと、計測時間がゼロにリセットされます。

## ログ

アプリケーションの実行ログは、プロジェクトのルートディレクトリにある `app.log` ファイルに出力されます。また、コンテナの標準出力でも確認できます。
```bash
docker-compose logs -f web
```
